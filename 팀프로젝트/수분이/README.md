
# 수분이

## 프로젝트 소개

아두이노와 센서 데이터를 활용하여 수면 상태를 분석하는 프로젝트입니다.

## 프로젝트 목적

수면 중 수집되는 센서 데이터를 활용하여 수면 상태를 분석하고,
이를 바탕으로 수면 관리에 도움을 줄 수 있는 서비스를 구현하고자 했습니다.

## 주요 내용

- 아두이노 기반 센서 데이터 수집
  - ecg 센서 및 산소 포화도등 측정

- 수면 관련 데이터 측정 및 분석
  - 생체신호 데이터 분석에 어려움을 겪어 머신러닝 & 딥러닝은 사용하지 못함
  - 데이터를 정체하고 가공하여 화면에 출력구현

- 수집된 데이터를 활용한 수면 상태 분석
  - 데이터 베이스 저장 및 입력 출력, erd 기록,반응형 웹 앱 구현
  - 수면 상태를 시계열로 보여주는 것까지 구현

- 수면 분석 결과를 활용한 서비스 구상
  - 어도비 인벤터를 이용하여 3d 모델 목업 제작 - 3d printer 로 시제품 제작
  - flask, mysql, postgresql 로 데이터 입출력
  - 프론트엔드 단에서 화면 출력 

## 사용 기술

- Arduino, esp32
- flask, mysql, postgresql, dbever
- html, css, javascript
- 센서(ecg, 산소포화도)
- adobe inventer, 3d printer
- Python
  - pandas, 생체 신호 분석 라이브러리


## 담당 역할

> 데이터 베이스 모델링, flask 백엔드 입출력 구현 

## 프로젝트 결과

> iot 사물지능 반 2위 

## 현재 상태

과거 팀 프로젝트로 진행했던 프로젝트입니다.

푸리에 분석등 생체신호 데이터 처리와 머신러닝, 딥러닝 등 각종 프로그래밍 스킬의 부족으로 인해 많은 부분이 완성되지 못했습니다. 

현재는 프로젝트의 코드를 다시 분석하고 부족한 부분을 보완하는 작업을 진행할 예정입니다.
