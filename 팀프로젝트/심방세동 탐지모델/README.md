# 심방세동 탐지모델

## 프로젝트 소개

ECG(심전도) 데이터를 활용하여 심방세동의 이상 유무를 이진 분류하는 딥러닝 기반 탐지 시스템을 구현한 프로젝트입니다.

`HarBud` 팀으로 3명이 함께 프로젝트를 진행했으며, 다양한 딥러닝 모델을 구현하고 ECG 데이터에 적용하여 분류 성능을 확인했습니다.

## 프로젝트 배경

이전 `수분이` 프로젝트에서 ECG 센서와 같은 생체신호 데이터를 직접 다루면서 생체신호 분석에 관심을 가지게 되었습니다.

당시에는 생체신호 데이터를 활용한 머신러닝과 딥러닝 모델을 직접 구현하지 못했던 아쉬움이 있었고, 이를 보완하기 위해 ECG 데이터를 활용한 딥러닝 기반 분류 프로젝트를 진행하게 되었습니다.

## 프로젝트 목적

ECG 데이터를 활용하여 심방세동의 이상 유무를 이진 분류하고, 생체신호 데이터에 다양한 딥러닝 모델을 적용하는 과정을 학습하고 구현하는 것을 목적으로 했습니다.

## 데이터

* PTB-XL ECG 데이터셋
* ECG Lead I 데이터
* 심방세동(AFIB) 여부를 기준으로 이진 분류
* 데이터의 클래스 불균형 확인
* 별도의 SPH 데이터셋을 활용한 추가 테스트 코드 구현
